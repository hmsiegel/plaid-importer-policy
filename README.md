# Privacy Policy — Plaid Importer

Last updated: October 12, 2026

## What this is
Plaid Importer is a personal, single-user application operated by its owner to
copy the owner's own bank transactions into the owner's own personal budgeting
software (Actual Budget). It is not offered to the public, and it has no
customers or other users.

## Information the application handles
The application handles the owner's own financial information, including bank
account details and transaction data, which it receives through Plaid. It also
stores the credentials and tokens needed to connect to the owner's banks (via
Plaid) and to the owner's Actual Budget server.

## How the information is used
The information is used only to import the owner's transactions into the
owner's own budget. It is not used for advertising, marketing, profiling, or
any other purpose.

## Who receives the information
- **Plaid**, which connects to the owner's financial institutions. Plaid's
  handling of data is governed by its own policy: https://plaid.com/legal/
- **Actual Budget server**, which is operated by the owner.
- **Fly.io**, the hosting provider on which the application runs.

The information is not sold, rented, or shared with anyone else.

## Security
Plaid access tokens and stored credentials are encrypted at rest. All
connections to the application use HTTPS (TLS). Access to the application is
restricted to the owner.

## Retention and deletion
The application keeps the information it needs to keep the owner's budget in
sync. The owner can disconnect a bank at any time, which stops further data
collection for that connection, and can delete stored data by removing the
connection and the application's data volume. The owner can also manage or
revoke Plaid connections at https://my.plaid.com.
